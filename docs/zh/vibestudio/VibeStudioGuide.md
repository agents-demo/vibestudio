# VibeStudio —— 用户指南

## VibeStudio 是什么？

VibeStudio 让你通过对话构建 React 应用。你描述想要什么，一队 WorkSwarm AI 智能体编写代码，
并为你展示实时预览——全部在浏览器中完成，无需编码。

---

## 开始使用

1. 确保 WorkSwarm 正在运行。参见 [VibeStudioInstall.md](VibeStudioInstall.md)。
2. 在浏览器中打开 VibeStudio（默认：`http://localhost:5174`）。
3. 你会进入**仪表盘**。

---

## 仪表盘

仪表盘是你的项目主界面。

### 创建项目

在**新项目**字段中输入项目名称（或留空以使用「未命名项目」），点击**创建**。

你也可以点击某个**模板提示片**来用现成创意预填名称——便于快速上手。

### 打开项目

点击任意项目卡片即可打开 Studio 工作区。

### 重命名项目

**双击**卡片中的项目标题。出现内联输入框。编辑名称并按 **Enter**（或点击外部）保存。按
**Escape** 取消。重命名会立即反映在本地列表和 WorkSwarm 会话中。

### 删除项目

悬停项目卡片，点击右上角出现的 **✕** 按钮。这会从 WorkSwarm 删除会话，并从列表中移除。

### 主题切换

页头中的 **☾ 深色 / ☀ 浅色** 按钮切换颜色主题。你的偏好会在会话之间记住。

---

## Studio 工作区

打开项目后进入 Studio。

```
┌─────────────────────────────────────────────────────────────────────────┐
│  V 仪表盘 / 项目名      </> 代码  ↩ 撤销  ↓ ZIP  ↓ 聊天  ✕               │
├───────────────┬──────────────────────────────┬───────────────────────────┤
│  聊天面板      │  ⇽ 可调整间隙                │  实时预览（主体）          │
│  （提示、      │                              │  ┌───────────────────────┐│
│  回复、        │                              │  │  你的应用              ││
│  内联 swarm    │                              │  └───────────────────────┘│
│  活动）        │                              │  ⇡ 代码抽屉（可选）        │
└───────────────┴──────────────────────────────┴───────────────────────────┘
```

工作区围绕**预览**组织：它总是获得剩余空间。**聊天**是左侧的驱动（可调整大小），**代码**
是从工具栏切换的单一抽屉。

### 聊天面板

在底部文本框中输入请求，按 **Enter**（或 **Shift+Enter** 换行）或点击**发送**。当 swarm
工作时，发送按钮变为**停止**，以便取消生成。

面板显示：
- 你的消息（右对齐，蓝色）。
- 智能体回复实时流式输出（左对齐）。
- 一个可折叠的**Swarm 活动**区域，在智能体工作时自动打开。它列出每个智能体的步骤和思考，
  带时间戳，生成完成时折叠为紧凑的「N 个步骤」页头。

### 实时预览

右侧在第一次生成完成后立即在浏览器中实时显示你的应用。每当生成新文件时自动刷新。预览使用
esbuild 本地打包，因此不需要互联网。

### 代码抽屉

- 点击 **`</> 代码`** 显示或隐藏**代码抽屉**，即预览底部一个可调整大小的面板。它并排显示
  **文件浏览器**和**代码编辑器**。
- 点击树中的文件会在编辑器中打开。
- 向上拖动抽屉手柄给代码更多空间——预览保留顶部空间。
- 拖动聊天与预览之间的手柄可调整聊天列宽度。面板大小会在访问之间记住。

使用工具栏中的 **✕ 清除** 清空对话视图。

---

## 生成你的第一个应用

1. 输入你想构建的内容，例如：
   > *「构建一个带标签、优先级和深色模式开关的待办应用」*
2. 按 **Enter**。
3. 观察状态气泡——一个智能体团队正在规划、编写和审查代码。首次生成需要 20–60 秒。
4. 生成完成时实时预览出现在右侧。

---

## 精炼你的应用

首次生成后，你可以继续聊天以更改任何内容：

| 意图 | 示例提示 |
|---|---|
| 更改外观 | *「把页头改成深蓝色并使用圆角按钮」* |
| 添加功能 | *「添加一个过滤任务列表的搜索栏」* |
| 修复 bug | *「删除按钮不工作，请修复」* |
| 解释代码 | *「解释过滤逻辑如何工作」* |
| 重构 | *「把任务列表重构为单独组件」* |

VibeStudio 自动检测你是想要完整重新生成（使用完整智能体团队）还是定向修改（使用单个快速
智能体）。

---

## 代码开关（`</> 代码`）

默认只显示实时预览。点击工具栏中的 **`</> 代码`** 在预览底部的可调整抽屉中显示 Monaco
代码编辑器。

### 文件标签页

所有项目文件以标签页形式出现在编辑器顶部。点击任意标签页切换到该文件。活动标签页带有彩色
下划线。如果标签页超过可容纳数量，条带会水平滚动。

### 编辑文件

Monaco 编辑器完全可编辑。你做的修改会被防抖（800 毫秒）并写回项目——**编辑稳定后实时预览
会自动重建**。小幅调整无需提示。

当文件有未保存的更改时，标签页上会出现小圆点（●）。写入完成后圆点消失。如果 swarm 重新生
成了你正在编辑的文件，Monaco 会更新显示生成版本，脏点被清除。

### 文件列表

点击编辑器右上角的**文件**按钮，在编辑器旁切换可折叠的文件树。点击树中的文件会切换到该
标签页。

再次点击 **`</> 代码`** 隐藏抽屉并返回全宽预览。

---

## 撤销 / 回退

每次成功生成后，工具栏中出现 **↩ 撤销** 按钮。点击它向 WorkSwarm 发送回退请求，它会将会话
回滚到该次生成之前的状态。VibeStudio 会恢复文件映射以匹配。

你可以多次撤销，逐步回退生成历史。

---

## 下载项目

文件生成后，工具栏中出现 **↓ ZIP** 按钮。点击它会将全部生成源文件打包为 ZIP 存档并下载到
你的机器——完全在浏览器中完成，无需服务器。

ZIP 包含原始目录结构下的源文件，可在任意代码编辑器中打开或手动部署。

---

## 主题切换

点击 **☾ 深色** 切换到深色模式，或 **☀ 浅色** 切换到浅色模式。偏好会自动保存并在下次访问
时恢复。

该开关同时出现在仪表盘页头和 Studio 工具栏中。

注意：**实时预览窗格**运行在隔离的浏览器框架中——其背景和颜色由生成的应用自身 CSS 决定，
而非 VibeStudio 的主题。

---

## 项目持久化

你的项目存储在浏览器的 `localStorage` 中。这意味着：

- 项目在页面刷新和浏览器重启后保留。
- 重新打开项目时自动恢复生成的文件——无需重新生成。
- 清除浏览器存储会移除所有项目。如果想保留代码，请先下载 ZIP。

---

## 模板

仪表盘在**创建**按钮旁有一个**使用模板**按钮。点击打开模板选择器——一个包含六个现成模板
项目的弹窗：

| 模板 | 构建内容 |
|---|---|
| 待办应用 | 带优先级、标签和深色模式的任务列表 |
| 落地页 | SaaS 风格 hero、定价、FAQ 和邮件表单 |
| 财务仪表盘 | 带图表的收支追踪器 |
| 食谱书 | 可搜索的食谱、收藏和购物清单 |
| 看板 | 存储在 localStorage 中的拖拽列 |
| 聊天界面 | 带时间戳的精致消息布局 |

选择模板会创建新项目，并在你进入 Studio 时立即发送完整生成提示——无需输入。

---

## 快捷操作按钮

聊天面板在输入框下方显示四个胶囊按钮：

| 按钮 | 效果 |
|---|---|
| **生成** | 移除任何已有前缀——纯生成 |
| **修复** | 在消息前添加 `Fix: ` |
| **解释** | 在消息前添加 `Explain: ` |
| **重构** | 在消息前添加 `Refactor: ` |

在切换操作时前缀会被剥离并替换，因此你永远不会得到双重前缀。你也可以手动输入前缀——意图
检测的工作方式相同。

---

## Swarm 活动

智能体工作时，聊天面板底部会出现一个可折叠的**Swarm 活动**区域：

- 生成开始时自动打开，完成时折叠为紧凑的「N 个步骤」页头——你的注意力留在聊天中。
- 每个条目显示墙钟时间戳。智能体步骤按角色着色（架构师、前端、后端、数据库、QA）；
  工具调用和思考有自己的徽标。
- 过长的推理文本会被截断——点击**显示更多**展开。
- 点击**清除**清空日志。

该区域纯属信息性——不影响生成。折叠它永远不会清除日志。

在移动端，活动会内联显示在**聊天**标签页中——无需额外标签页。

---

## 智能体澄清（HITL）

有时智能体团队在缺少更多上下文时无法做决定——例如你要求「一个设置页面」但应用没有现有
设置。此时聊天中会出现一个**澄清卡片**，而非普通消息：

```
┌─────────────────────────────────────────────┐
│ swarm 需要澄清                               │
│                                             │
│ 设置页面应包含用户账户选项，还是仅外观        │
│ 偏好？                                      │
│                                             │
│ [输入你的回答…                     回复]      │
└─────────────────────────────────────────────┘
```

输入你的回答并按**回复**（或 **Enter**）。智能体会收到你的回答，并从暂停处继续生成。
你无需重新发送原始提示。

**提示：**
- 要具体。「账户 + 外观，但不要计费」比「都要」更好。
- 如果不确定，简要回答——智能体会对未涉及的内容做出合理假设。
- 生成完成后，你随时可以用后续提示精炼。

---

## 导出聊天

一旦你交换了至少一条非状态消息，Studio 工具栏中就会出现 **↓ 聊天** 按钮。点击它会下载包含
完整对话的 Markdown 文件（`<project-name>-chat.md`），适合分享或归档。

文件使用简单格式：

```
# 项目名
_导出时间：<时间戳>_

**你：** 你的消息…

**智能体：** 智能体回复…

> _智能体状态：规划中…_
```

## 在移动端使用 VibeStudio

VibeStudio 会自动适配小屏幕。在宽度小于 768 px 的屏幕上，并排布局被工作区顶部的标签栏取代：

| 标签页 | 内容 |
|---|---|
| **聊天** | 全屏聊天面板（包含内联 swarm 活动） |
| **预览** | 全屏实时预览 |
| **代码** | 全屏 Monaco 编辑器（所有文件标签页，可编辑） |

所有工具栏按钮仍可在屏幕顶部使用。

---

## 重连

如果与 WorkSwarm 的连接断开（例如服务器重启），屏幕底部会出现横幅：

> 🔴 已与 WorkSwarm 断开——正在重连…

客户端使用指数退避自动重试。连接恢复后横幅立即消失，任何进行中的生成继续。

---

## 故障排查

**聊天面板中「已断开——正在重连…」**
: WorkSwarm 服务器不可达。检查它是否在 `ws://localhost:19000`（或你在 `.env` 中配置的
  URL）运行。SDK 会以指数退避自动重试。

**生成后预览保持空白**
: 生成的应用可能有构建错误。点击 **`</> 代码`** 打开 Monaco 编辑器检查生成的文件。打包失败
  时预览面板会显示「预览构建失败」和 esbuild 错误消息。

**生成花费很长时间**
: 团队模式（用于「生成」意图）按顺序运行多个智能体。大型或复杂的应用可能需要 60–90 秒。
  你可以在工具栏旋转器中看到当前活动的智能体。

**刷新后项目文件消失**
: 这可能是浏览器 `localStorage` 配额超限所致（大型项目时少见）。请定期下载 ZIP 作为备份。

**撤销不可用**
: ↩ 撤销按钮只会在当前会话至少有一次成功生成后出现。如果你刷新了页面，回退历史会被重置
  （不过生成的文件仍会恢复）。
